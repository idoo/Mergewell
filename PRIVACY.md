# Mergewell Privacy Policy

**Effective Date:** 2026-01-23
**Developer:** Ivan Verevkin
**Contact:** ivan@0x.se

Mergewell is a small, local-first tool for detecting and resolving Git merge conflicts. This Privacy Policy explains what data the app accesses, how it is used, and the choices you have.

## Information We Collect
- **Repository & File Contents (local only):** To detect and resolve merge conflicts Mergewell reads files in your Git working tree and reads Git metadata. These operations occur on your machine and are not uploaded externally.
- **Device/Environment Info:** Basic environment details (OS name/version, Git version) may be accessed to ensure compatibility and provide helpful messages. This information is not tied to you personally.
- **No Personal Identifiers:** Mergewell does not collect names, emails, location, or other personal identifiers by default.

## How We Use Your Information
- **Core Functionality:** Local repository and file contents are used only to detect conflict markers, render diffs, and apply resolutions as you choose.
- **Diagnostics & Compatibility:** Environment information is used to improve compatibility and guide troubleshooting.
- **No Automatic Sharing:** Mergewell does not send your repository data or files to external servers.

## Data Storage and Security
- **Local Storage:** All edits, resolutions, and temporary files are written to your local working tree. Mergewell may create temporary files while editing; these are stored locally and removed as appropriate.
- **No Cloud Collection:** Mergewell does not transmit repository contents or user data to cloud services by default.
- **Security Measures:** Reasonable safeguards are used to protect local operations, but no software can be guaranteed 100% secure. You should follow standard repository backup and security practices.

## Third Parties
- Mergewell does not share your data with third parties. If you opt into any future integrations (for example, optional analytics or cloud backup), the policy will be updated and opt-in consent will be requested.

## Your Choices
- **Local Only:** You can use Mergewell entirely offline; no network access is required for core features.
- **Opt-Out:** If an optional feature that collects non-local data is introduced, you will be given a clear opt-in choice and an option to opt out later.
- **Uninstall:** Deleting the application removes Mergewell binaries; any files in your repository remain under your control.

## Children’s Privacy
Mergewell is not intended for children under 13. We do not knowingly collect personal information from children.

## Changes to This Policy
We may update this policy when the app changes or new features are added. If material changes are made that affect data handling, we will update this document and note the revised effective date.
